Aanmaken (gratis): ga naar developer.nytimes.com → maak een account → Apps → + New App → zet Books API aan → maak de app en kopieer de API Key.

Kindle (Send to Kindle)

Elke Kindle heeft een eigen @kindle.com-adres (Amazon → Inhoud & apparaten → Voorkeuren → Persoonlijke documenten). Zet daar je afzenderadres bij “Goedgekeurde e-mailadressen”, anders weigert Amazon de mail. Voor Gmail: gebruik smtp.gmail.com, poort 587 en een app-wachtwoord.

Leesapps (OPDS)

Voeg deze link toe in een leesapp (KOReader, Thorium, Moon+ Reader, Librera, Marvin…) om je bibliotheek te bladeren en boeken te downloaden over je wifi.
